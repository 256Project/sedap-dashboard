# Akbar — mobil tekshiruv

Kod darajasida: planshetda statistika 2 ustun, 768–900 px grafiklar 1 ustun, mobil inputlar 16 px, jadval ichida gorizontal scroll, modal dinamik ekran balandligiga mos. Mobil Sidebar fokusni ichida saqlaydi, Escape bilan yopiladi, desktopga o‘tilganda scroll blokirovkasi yechiladi.

Brauzerda quyidagilar **hali tekshirilmagan**. Tekshirilgandan keyingina [x] qo‘yiladi.

O‘lchamlar: 320, 375, 390, 768, 820, 1024, 1440 px.

- [ ] Login: maydonlar, xato xabarlari, parol tugmasi, klaviatura ochilganda scroll.
- [ ] Dashboard: sahifa tashqariga chiqmasligi, kartalar, donutlar, davr tanlash va tooltiplari.
- [ ] Wallet: balans, grafik, filtr, bo‘sh natija, sahifalash va jadval ichidagi gorizontal scroll.
- [ ] Sidebar: ochish/yopish, fonni bosish, Escape, Tab/Shift+Tab fokus aylanishi.
- [ ] Menyu ochiq holda desktop o‘lchamga o‘tish: body scroll yana ishlashi.
- [ ] Modal: ochish, Tab fokus, Escape, tashqi fon, fokusning oldingi tugmaga qaytishi.
- [ ] Logout va himoyalangan route’ga to‘g‘ridan-to‘g‘ri kirish.
- [ ] Sedap dizayni bilan rang, shrift, ikonka va joylashuvni vizual taqqoslash.

Agent brauzer inventari bo‘sh bo‘lgani sababli bu ro‘yxat avtomatik tasdiqlanmadi. Production build va Vercel deploy alohida tekshiriladi.
